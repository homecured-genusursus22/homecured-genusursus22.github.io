## 🎯 What is Presence?

Presence is a simple Windows application that shows what you're working on in your Discord profile. Whether you're making music in FL Studio, writing code, or using creative tools, Presence automatically displays your current activity to your friends and community.

Think of it as a window into your creative world - instead of just showing "Online" on Discord, your friends will see "Working on a new beat in FL Studio 26" or "Coding in Visual Studio Code." It's perfect for streamers, content creators, and anyone who wants to share their workflow.

## 🎮 How It Works

When Presence is running, it quietly works in the background. Here's what happens:

1. It detects which application you have open
2. It reads basic information about your current project
3. It sends this to Discord to display on your profile

The entire process is automatic. You don't need to do anything - just start working and your Discord status updates itself.

## ❓ Frequently Asked Questions

### 🔧 Is It Safe?
Absolutely! Presence only reads basic window titles and application names. It never accesses your files or sends data anywhere except to Discord.

### 💰 How Much Does It Cost?
Presence is completely free and open-source. You can use it forever at no cost.

### 🔄 Does It Use a Lot of Resources?
No, Presence is very lightweight. It uses less than 50 MB of RAM and has minimal CPU usage.

### 🐛 What If It Doesn't Work?
Most issues are solved by:
- Making sure Discord is running
- Checking that Presence is running in the system tray
- Restarting both applications
- Making sure you have the latest version

### 📱 Can I Use It on Mac?
Currently, Presence is for Windows only. We're working on a Mac version for the future.

## 🛠️ Troubleshooting Guide

### Problem: Status Not Showing
- Check if Presence is running (look for the icon in your system tray)
- Restart Discord
- Verify your Discord settings allow rich presence

### Problem: Wrong Application Detected
- Wait a few seconds - sometimes it takes time to update
- Check if the application is properly installed
- Try restarting the application

### Problem: Can't Install
- Make sure you have Windows 10 or 11
- Run the installer as administrator
- Check your internet connection
